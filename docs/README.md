## Convenções

- **[DECIDIDO]**: decisão aprovada ou derivada de requisito aprovado.
- **[SUPOSIÇÃO]**: hipótese a validar; veja as premissas em [riscos](11-riscos-decisoes-e-auditoria.md).
- **[TBD]**: decisão pendente, com dono e gatilho.
- **MVP / PÓS**: escopo previsto para a primeira versão / posterior. O GDD tem conflitos de prioridade; não assuma que foram resolvidos.
- **u**: unidade de mundo, aproximadamente 1 px na resolução lógica 1280 × 720. **s**: segundo de jogo; 1 s real corresponde a 1 s de jogo ativo. **CR**: créditos.

Os IDs e números são os do material de referência. A documentação registra o planejamento, não evidência de implementação, testes, desempenho ou aprovação de uma versão de software.
